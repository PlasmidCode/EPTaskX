# Prediction Experiment Results

This directory keeps only curated benchmark snapshots used by the prediction experiments.

## Retained Snapshots

- `unified_benchmark_v4/`: pre-optimization baseline used for regression checks.
- `unified_benchmark_v5/`: refined benchmark with scheduler forecast export and interval metrics.
- `unified_benchmark_v6/`: GPU/AMP run with validation-based calibration and v5/v6 comparison tables.

Ad-hoc benchmark runs, smoke tests, TensorBoard logs, checkpoints, and legacy result folders are ignored by git.
